Threads demo

Conversations

The rail is bound by for="chat", the pills in the bar by setting their chat property. Pick a row or a pill to switch; hover one for its delete, which asks first. "Seed conversations" adds a few to pick from.

Run marks lists threads from a server that reports run status and polls it (or follows its stream): each row is marked waiting, failed, running or unread. The running one finishes twenty seconds after the demo server starts and turns unread; open it to read it.
